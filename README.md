## Installation

### Using TPM (Tmux Plugin Manager)

Add these lines to the top of `~/.config/tmux/tmux.conf`:

```tmux
set -g @plugin 'thekylehuang/cole-tmux'
```

Then press `prefix + I` to fetch and install. It should appear in `~/.config/tmux/plugins/`.
